You are a casual game designer for Saudi youth. Create a genuinely FUN, polished HTML mini-game about arranging story cards into the right order. If it feels like a sequencing exercise, you failed.

## CRITICAL: Make It a Real Game
Player is building a visual story/timeline. English sentences are story pieces. The joy is in seeing the story come together beautifully — not in "getting the order right."

Think: building a comic strip, arranging photos into an album, completing a puzzle.

## Juice Requirements (MUST implement at least 5)
1. **Satisfying snap**: Cards physically snap into slots with bounce + scale animation
2. **Glow trail**: When card is dragged, a subtle glow/particle trail follows it
3. **Slot magnets**: Slots pulse and brighten as card approaches, "pulling" it in
4. **Story playback**: When all slots filled correctly, cards animate in sequence — each card lights up briefly in order, showing the complete story
5. **Sparkle trail**: A sparkle particle travels along the timeline connecting all placed cards
6. **Wrong bounce**: Incorrect order → cards gently float back to their original positions (not red shake)
7. **Screen celebration**: Complete story → subtle screen glow + particle burst
8. **Collection gallery**: Completed stories appear as mini-thumbnails in a gallery row

## Structure: Story Builder (Multi-Screen)
3 screens with CSS transitions (opacity + transform fades), no page reloads:
- **Splash (1.5s)**: game title, large emoji, simple CSS spinner. Fade out to game.
- **Game**: the story-building gameplay as described.
- **Results**: story gallery display, play again button.

## Mobile Game Features (REQUIRED)
**Sound** (Web Audio API, no files): generate beeps with oscillator. sfxCorrect() = ascending two-tone. sfxWrong() = low triangle. sfxSnap() = short click when card snaps into slot. sfxStoryComplete() = celebratory arpeggio.
**Haptic**: `navigator.vibrate` — correct=30ms, wrong=[50,50,50], snap=15ms.
**PWA**: embed manifest as data URI with standalone display.
**localStorage**: save best score, total plays, completed stories count. Key: `"saudi_game_progress"`.

## Structure: Story Builder (original)
- Player sees empty timeline slots (Step 1, Step 2, Step 3, Step 4)
- Draggable story cards float above, shuffled
- Drag a card into a slot → it snaps in with animation
- All slots filled → auto-check → if correct, story plays. If wrong, cards float back.
- After 3-4 stories → gallery of completed stories

- Dark atmospheric theme (night city, neon glow, Boulevard World vibes)

- `touch-action: manipulation` on all interactive elements
- Minimum touch target 48x48px for all clickable/draggable elements
- Body: `overflow: hidden`. Container height: `100dvh` for iOS Safari

- Portrait phone, one-handed play assumption

## Anti-Patterns (FORBIDDEN)
- "Round X of Y" numbering
- "Correct!" / "Wrong!" popup text
- Red X shake on wrong → use gentle float-back instead
- Clinical slot design → use warm, glowing, inviting slots
- Progress dots

## Technical

- Prevent touchmove default during drag. CSS custom properties. RTL support.
